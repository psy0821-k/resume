Intro

안녕하세요. 사용자가 편하게 사용할 수 있는 웹을 만드는 프론트엔드 개발자 박성윤입니다.

단순히 화면을 구현하는 것에 그치지 않고, 사용자의 흐름과 인터랙션을 고려해 직관적인 UI를 설계하고 구현합니다.

Semantic HTML과 WAI-ARIA를 기반으로 웹 접근성을 고려하며, Lighthouse와 Chrome DevTools를 활용해 성능과 접근성을 직접 측정하고 개선합니다.

또한 반복되는 UI와 기능은 재사용 가능한 컴포넌트로 분리하여 유지보수성과 개발 효율을 높이는 것을 중요하게 생각합니다.

주요 개발 역량

01

UI Engineering

사용자의 흐름과 인터랙션을 고려해 직관적인 UI를 구현합니다. 반복되는 UI와 기능은 재사용 가능한 컴포넌트로 분리해 일관성과 유지보수성을 높입니다.

02

Performance

Lighthouse와 Chrome DevTools를 활용해 렌더링과 리소스를 분석하고, 실제 배포 환경에서 발생하는 성능 문제를 측정하고 개선합니다.

03

Accessibility

Semantic HTML과 WAI-ARIA를 기반으로 키보드 탐색과 포커스 흐름을 고려하고, 다양한 사용자가 이용할 수 있는 접근 가능한 UI를 구현합니다.
